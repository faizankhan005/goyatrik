## 🎯 About GoYatrik

<table>
<tr>
<td width="55%">

**GoYatrik** *("Yatrik" — traveler, in Hindi)* is a full-stack SaaS travel platform engineered to make trip planning **easy, affordable, secure, and accessible** through modern technology and delightful design.

It unifies every leg of a journey — ✈️ **flights**, 🏨 **hotels**, 🚆 **trains**, 🚌 **buses**, and 🗺️ **curated tour packages** — into a single, seamless booking experience, layered with an **AI travel assistant** that helps travelers plan smarter, faster.

> 🎯 **Mission** — Make travel planning easy, affordable, secure, and accessible through innovative technology and exceptional customer experiences.
>
> 🌍 **Vision** — Become a globally trusted travel platform connecting millions of travelers with unforgettable journeys.

</td>

## 📁 Project Structure

```bash
goyatrik/
├── actions/                 # Server actions — auth, booking, tour, upload
├── app/
│   ├── (admin)/admin/        # 🛠️  Admin dashboard
│   ├── (auth)/               # 🔐 Login & register
│   │   ├── login/
│   │   └── register/
│   ├── (public)/              # 🌐 Public-facing pages
│   │   ├── about/              # Company story, mission & founder
│   │   ├── buses/               # Bus search & booking
│   │   ├── contact/              # Contact page
│   │   ├── flights/               # Flight search & booking
│   │   ├── hotels/                 # Hotel search & booking
│   │   ├── trains/                  # Train search & booking
│   │   └── tours/                    # Tour listing + [id] detail pages
│   └── (user)/                        # 👤 Authenticated user area
│       ├── bookings/                   # Booking history + [id] detail
│       ├── dashboard/                    # User dashboard
│       └── profile/                       # Profile management
├── components/
│   ├── booking/            # BookingForm, BookingSummary
│   ├── details/             # TourDetails
│   ├── home/                  # Hero, Offers, PopularTours, SearchBox, Testimonials
│   ├── layout/                  # Navbar, Footer, MobileMenu
│   ├── tours/                     # TourCard, TourFilters, TourGrid
│   └── TravelWidget.tsx             # Global travel search widget
├── data/                    # Static / seed data
├── database/                 # SQL schema, RLS policies, seed data
├── hooks/                      # useAuth, useBooking, useTours
├── lib/                          # supabase/, cloudinary.ts, openai.ts, razorpay.ts
├── services/                      # Service layer (auth, etc.)
├── store/                           # Zustand stores
├── types/                             # Shared TypeScript types
└── validations/                        # Zod schemas
```

## 🚀 Getting Started

### ✅ Prerequisites

![Node](https://img.shields.io/badge/Node.js-18+-339933?style=flat-square&logo=node.js&logoColor=white)
![npm](https://img.shields.io/badge/npm%2Fyarn%2Fpnpm%2Fbun-supported-CB3837?style=flat-square&logo=npm&logoColor=white)

- Node.js **18+**
- npm / yarn / pnpm / bun
- A [Supabase](https://supabase.com) project
- A [Razorpay](https://razorpay.com) account (payments)
- A [Cloudinary](https://cloudinary.com) account (media uploads)
- An [OpenAI](https://platform.openai.com) API key (AI features)

### 📦 Installation

```bash
# 1. Clone the repository
git clone https://github.com/faizankhan005/goyatrik.git
cd goyatrik

# 2. Install dependencies
npm install
```

### ⚙️ Environment Variables

Create a `.env.local` file in the project root:

```env
# ── Supabase ──────────────────────────────
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

# ── Razorpay ──────────────────────────────
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret

# ── Cloudinary ────────────────────────────
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# ── OpenAI ────────────────────────────────
OPENAI_API_KEY=your_openai_api_key
```

### ▶️ Run the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open **[http://localhost:3000](http://localhost:3000)** to see it running locally. 🎉

### 🔧 Other scripts

```bash
npm run build   # Production build
npm run start   # Start production server
npm run lint    # Run ESLint
```
